# Langchain-Retriever

A repository exploring LangChain retrievers, indexing, and vector store retrieval strategies for Retrieval-Augmented Generation (RAG) pipelines.

## Overview

This repository focuses on building and evaluating various retrieval mechanisms in LangChain, including:
- Vector store retrievers (similarity search, MMR - Maximal Marginal Relevance)
- Contextual compression retrievers
- Multi-query retrievers
- Hybrid search and ensemble retrievers

## Getting Started

### Prerequisites
- Python 3.10+
- Virtual environment (`venv` or `uv`)

### Installation
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install langchain langchain-community langchain-core
```
